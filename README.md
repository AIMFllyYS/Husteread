## 🏗️ 技术架构与基础设施

本平台基于现代化全栈架构构建，所有服务均部署于**中国境内**，确保数据合规：

| 基础设施 | 服务商 | 具体服务 | 用途 |
|---------|--------|---------|------|
| **应用服务器** | 阿里云 | ECS 云服务器 | 网站运行环境 |
| **数据库** | 阿里云 | RDS PostgreSQL | 用户数据与内容存储 |
| **文件存储** | 阿里云 | OSS 对象存储 | 图片、附件等文件存储 |

## 🔐 信息收集与隐私保护

### 我们收集什么

本平台遵循**最小必要原则**，仅收集运营所必需的最少量信息：

| 收集项目 | 用途 | 敏感度 | 存储位置 |
|---------|------|--------|---------|
| 邮箱地址 | 账号注册与登录验证 | 低 | 阿里云 RDS PostgreSQL（中国境内，加密传输） |
| 用户昵称 | 社区展示身份 | 低 | 阿里云 RDS PostgreSQL（中国境内，加密传输） |
| 姓名 | 活动签到/出勤统计 | 低 | 阿里云 RDS PostgreSQL（中国境内，活动结束 90 天后自动清除） |
| 到场状态 | 活动出勤记录 | 低 | 阿里云 RDS PostgreSQL（中国境内，活动结束 90 天后自动清除） |
| 上传图片 | 活动照片 / 文章配图 | 低 | 阿里云 OSS 对象存储（中国境内，自动剥离 EXIF 地理信息） |

### 我们绝不收集

> **🚫 本站承诺永不收集以下敏感个人信息：**

- ❌ 手机号码
- ❌ 学号 / 学籍信息
- ❌ 身份证号码
- ❌ 家庭住址
- ❌ 银行卡 / 支付信息
- ❌ 生物识别信息（人脸、指纹等）
- ❌ 任何可直接定位到个人的敏感标识符

### 敏感信息如何处理？

对于确实需要收集手机号等敏感信息的场景（如部分活动报名），我们采用**分层收集策略**：

```
需要手机号的活动 → 跳转至飞书（Lark）平台收集
                    ├── 数据存储在飞书服务器（字节跳动企业级加密）
                    ├── 不经过本站服务器
                    ├── 不存储在本站数据库
                    └── 由飞书平台承担数据安全责任
```

**即：本站服务器上不会存在任何高敏感个人信息。**

### 数据安全措施

- 🔒 全站 HTTPS 加密传输
- 🔒 数据库部署于中国境内服务器（阿里云），符合国内数据合规要求
- 🔒 所有 API 接口均有身份验证和权限校验
- 🔒 实施 IP 限流、人机验证等反滥用机制
- 🔒 用户上传图片自动剥离 EXIF 地理位置信息
- 🔒 定期安全审计与漏洞扫描
- 🔒 完整安全评估报告请参见 [`docs/security-assessment.md`](docs/security-assessment.md)

### 数据删除权

用户有权随时要求删除其在本站的所有数据：
1. 通过个人中心「注销账号」功能自助删除
2. 发送邮件至 [contact@yusheng.email](mailto:contact@yusheng.email) 申请人工删除
3. 我们承诺在收到请求后 **72 小时内** 完成数据清除
