## 1. 概述

### 1.1 评估目的

本报告旨在对 HUSTERead 读书会展示平台进行全面的信息安全评估，证明本平台在设计、开发和运营层面已充分考虑并落实信息安全保护措施，确保用户数据安全。

### 1.2 评估范围

| 项目 | 说明 |
|------|------|
| **平台名称** | HUSTERead 读书会展示平台 |
| **平台性质** | 非官方学生社团展示网站 |
| **评估对象** | 网站前端、后端 API、数据库、文件存储、第三方集成 |
| **参考标准** | GB/T 22239-2019《信息安全技术 网络安全等级保护基本要求》 |
| | GB/T 35273-2020《信息安全技术 个人信息安全规范》 |
| | 《中华人民共和国个人信息保护法》(2021) |
| | 《中华人民共和国数据安全法》(2021) |

### 1.3 平台定级

根据 GB/T 22239-2019，本平台自我评估为**等保二级及以下**：

| 评估维度 | 说明 | 定级依据 |
|---------|------|---------|
| 信息系统规模 | 小型，预计用户 < 500 | 学生社团内部使用 |
| 处理数据敏感度 | 低 | 不收集手机号、学号、身份证等敏感信息 |
| 业务影响范围 | 极小 | 非关键基础设施，非商业运营 |
| 社会影响 | 极小 | 仅影响社团内部，不涉及公共服务 |

## 2. 数据资产分析

### 2.1 数据分类清单

#### 本站直接存储的数据

| 数据项 | 分类 | 敏感等级 | 存储位置 | 保留期限 |
|--------|------|---------|---------|---------|
| 用户邮箱 | 个人一般信息 | 🟢 低 | 阿里云 RDS (中国境内) | 账号存续期 |
| 用户昵称 | 个人一般信息 | 🟢 低 | 阿里云 RDS (中国境内) | 账号存续期 |
| 用户姓名 (活动签到) | 个人一般信息 | 🟢 低 | 阿里云 RDS (中国境内) | 活动结束后 90 天 |
| 到场状态 | 业务数据 | 🟢 极低 | 阿里云 RDS (中国境内) | 活动结束后 90 天 |
| 文章/帖子内容 | 用户生成内容 | 🟢 低 | 阿里云 RDS (中国境内) | 用户删除或账号注销 |
| 上传图片 | 用户生成内容 | 🟢 低 | 阿里云 OSS (中国境内) | 用户删除或账号注销 |
| 登录 IP 地址 | 日志数据 | 🟡 中 | 阿里云 RDS (中国境内) | 30 天自动清除 |

#### 本站绝不存储的数据

| 数据项 | 分类 | 处理方式 |
|--------|------|---------|
| 手机号码 | 个人敏感信息 | **绝不收集**，需要时跳转飞书平台 |
| 学号/学籍 | 个人敏感信息 | **绝不收集** |
| 身份证号 | 个人敏感信息 | **绝不收集** |
| 银行卡/支付 | 个人敏感信息 | **绝不收集**，网站无任何支付功能 |
| 生物识别 | 个人敏感信息 | **绝不收集** |
| 精确地理位置 | 个人敏感信息 | **绝不收集**，图片上传自动剥离 EXIF |

### 2.2 数据泄露影响评估

> **核心结论：即使发生最严重的数据泄露事件，对用户的实际危害极低，完全在可承受范围内。**

| 泄露场景 | 泄露数据 | 实际危害 | 危害等级 |
|---------|---------|---------|---------|
| 数据库完整泄露 | 邮箱 + 昵称 + 姓名 | 邮箱为公开信息级别，无法直接造成财产/人身损害 | 🟢 **极低** |
| OSS 存储泄露 | 活动照片 | 照片已剥离 EXIF，无地理位置信息，均为公开活动照片 | 🟢 **极低** |
| 日志泄露 | IP 地址(30 天内) | IP 为动态分配，无法直接定位个人 | 🟢 **极低** |
| 管理后台泄露 | 所有用户列表 | 仅含邮箱+昵称，无法进行钓鱼/勒索 | 🟢 **极低** |

**危害极低的根本原因：**

1. **不存在高价值攻击目标** — 无密码哈希、无支付信息、无身份证号
2. **数据组合威胁低** — 邮箱+昵称+姓名的组合无法用于身份盗用
3. **数据时效性差** — 签到数据 90 天自动清除，无长期隐私风险
4. **飞书责任隔离** — 手机号等高敏感数据不经过本站服务器

## 3. 安全防护措施

### 3.1 网络安全

| 措施 | 实施方案 | 对应标准 |
|------|---------|---------|
| 传输加密 | 全站 HTTPS (TLS 1.2+)，HSTS Header | GB/T 22239 7.1.4 |
| 防火墙 | 阿里云安全组 + WAF（Web 应用防火墙） | GB/T 22239 7.1.2 |
| DDoS 防护 | 阿里云 DDoS 基础防护 | GB/T 22239 7.1.3 |
| 入侵检测 | 阿里云云安全中心（基础版） | GB/T 22239 7.1.5 |

### 3.2 应用安全

| 措施 | 实施方案 | 防御目标 |
|------|---------|---------|
| 输入验证 | Zod Schema 校验所有 API 入参 | SQL 注入、XSS |
| 参数化查询 | Prisma ORM（原生参数化） | SQL 注入 |
| 内容消毒 | DOMPurify 渲染用户内容 | XSS（存储型） |
| CSP 策略 | Content-Security-Policy Header | XSS（反射型） |
| CSRF 防护 | Next.js 内置 CSRF Token + SameSite Cookie | CSRF |
| 文件上传校验 | 类型白名单 + 大小限制 + 病毒扫描 | 恶意文件上传 |
| EXIF 剥离 | 图片上传前自动移除地理位置等元数据 | 隐私泄露 |
| 依赖审计 | npm audit + Snyk 定期扫描 | 供应链攻击 |

### 3.3 身份认证与访问控制

| 措施 | 实施方案 | 说明 |
|------|---------|------|
| 认证方式 | 邮箱 Magic Link（无密码） | 消除密码泄露风险 |
| 会话管理 | JWT + HttpOnly + Secure + SameSite Cookie | 防会话劫持 |
| 会话过期 | 7 天自动过期，异常活动立即失效 | 降低被盗风险 |
| 角色模型 | RBAC 三级角色（visitor / member / admin） | 最小权限原则 |
| API 权限 | 每个 API 端点独立鉴权 | 防越权访问 |
| 管理面板 | 双重验证（登录 + 角色校验） | 防管理面板渗透 |

### 3.4 反滥用措施

| 措施 | 参数 | 说明 |
|------|------|------|
| 全局 IP 限流 | 100 请求/分钟/IP | 防爬虫/DDoS |
| 登录限流 | 5 次/小时/IP | 防暴力破解 |
| 邮件发送限流 | 3 封/小时/邮箱 | 防邮箱轰炸 |
| 发帖限流 | 10 篇/天/用户，间隔 ≥ 2 分钟 | 防垃圾灌水 |
| 人机验证 | 注册/发帖触发滑块验证 | 防机器人 |
| 邮箱验证 | 未验证邮箱不可发帖 | 提高滥用成本 |
| 敏感词过滤 | 关键词库 + 正则匹配 | 内容安全 |
| 内容审核 | 阿里云内容安全 API (图文) | 合规审查 |
| 举报机制 | 用户举报 → 管理员审核队列 | 社区治理 |

### 3.5 数据安全

| 措施 | 实施方案 | 说明 |
|------|---------|------|
| 传输加密 | TLS 1.2+ (客户端 ↔ 服务器) | 防中间人攻击 |
| 数据库连接加密 | SSL (服务器 ↔ RDS) | 防内网嗅探 |
| 数据备份 | 阿里云 RDS 自动备份（7 天） | 灾难恢复 |
| 密钥管理 | 环境变量存储，不入代码库 | 防密钥泄露 |
| 日志脱敏 | 日志中邮箱部分掩码显示 | 防日志泄露 |
| 数据保留 | 签到数据 90 天自动清除，IP 日志 30 天清除 | 最小保留 |
| 数据删除 | 用户可自助注销，72 小时内彻底清除 | 用户权利保障 |

## 6. 风险评估矩阵

| 风险编号 | 风险描述 | 可能性 | 影响度 | 风险等级 | 缓解措施 | 残余风险 |
|---------|---------|--------|-------|---------|---------|---------|
| R-001 | 数据库泄露 | 低 | 低 | 🟢 **低** | 阿里云安全组+WAF；无高敏感数据 | 可接受 |
| R-002 | XSS/CSRF 攻击 | 中 | 低 | 🟢 **低** | 内容消毒+CSP+CSRF Token | 可接受 |
| R-003 | 垃圾灌水 | 高 | 中 | 🟡 **中** | 限流+验证码+邮箱验证 | 可接受 |
| R-004 | 管理面板越权 | 低 | 中 | 🟢 **低** | RBAC+API 层权限校验 | 可接受 |
| R-005 | 内容违规 | 中 | 高 | 🟡 **中** | 内容审核 API+人工审核+举报机制 | 可接受 |
| R-006 | 服务不可用 (DDoS) | 低 | 低 | 🟢 **低** | 阿里云 DDoS 防护；非关键服务 | 可接受 |
| R-007 | 第三方服务中断 | 低 | 低 | 🟢 **低** | 飞书为可选通道；松耦合设计 | 可接受 |

### 风险总评

> **本平台整体安全风险等级为「低」。**
>
> 由于平台不收集任何高敏感个人信息，即使发生最严重的全量数据泄露事件，泄露数据仅包含邮箱、昵称、姓名等低敏感信息，**不会对用户造成财产损失或人身安全威胁**，危害完全在可承受范围内。
>
> 手机号等高敏感信息通过飞书平台收集和存储，与本站服务器完全隔离，进一步降低了本平台的数据安全责任和风险暴露面。

## 7. 安全事件应急预案

### 7.1 事件分级

| 级别 | 定义 | 响应时间 | 处置措施 |
|------|------|---------|---------|
| **P0 - 紧急** | 数据泄露确认 / 服务被入侵 | 1 小时内 | 立即关停服务，排查溯源，通知受影响用户 |
| **P1 - 严重** | 疑似攻击 / 异常流量 | 4 小时内 | 启用防护策略，分析日志，封禁可疑 IP |
| **P2 - 一般** | 垃圾灌水 / 内容违规 | 24 小时内 | 清理违规内容，封禁违规用户 |
| **P3 - 低危** | 功能异常 / 性能下降 | 72 小时内 | 排查修复 |
