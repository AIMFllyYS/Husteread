# 主办方：华中科技大学读书会
# 活动时间：2025年10月15日18:30
# 活动地点：东图书馆301

一、活动背景
为了把好电影带给大家，华中科技大学读书会开启了“tonight观影会”系列活动。东图书馆3楼放映厅放映交流会持续来袭，共度秋冬日时光，经大群投票决定选择剧情类电影观看。
二、活动筹备
1.确定电影
在读书会群中发起询问，选择电影为《霍乱时期的爱情》；
并准备片源、确保片源全程无卡顿；
负责人：xxx
确定主持人
提前准备主持内容，主要包括电影开始的发言、电影结束的讨论问题等；
在观影前后活跃现场气氛、发起讨论。
观影前：提醒到场同学扫码签到，影片简介、小互动；
观影后：发起讨论。
负责人：xxx
3，在图书馆官微阅读推广平台上线下活动里建立观影评论专题，设置预约及签到时间。专题内容含：
①活动基本情况：背景、形式、时间、地点、参与人
②影片名称、基本介绍、名家影评优质推荐（1-2条）
③规定评论发布格式：时间|观影地点|电影名|感言（150-200字）；
例：20201018|图书馆放映厅|《爱乐之城》|《爱乐之城》是一部奥斯卡获奖影片……
负责人：xxx
4，编写打卡操作流程发布，发布专题链接到会员大群、各部门群及各学习小组，确保每个成员提前知道，并在平台上完成活动预约；
负责人：xxx
制作电影宣传海报；
负责人：xxx
三、活动开展
①提前至少2天确定开始放映的具体时间内容地点并在大群通知，
提醒参与活动的同学在阅读推广平台预约本活动；
②电影观看；
③放映结束，组织大家进行讨论。
④线上评论打卡
观影当天完成阅读推广平台的观影评论专题打卡，
参与签到、评论视为参与本次观影，办公室做记录。
四、活动总结
1．活动记录
（办公室）在活动结束后对活动进行记录（建立标准记录表格），完成表格并及时提交指导教师
2．后期宣传
宣传部编辑推文，内容包括活动背景、活动基本参加情况，活动效果以及优秀线上评论展示。
